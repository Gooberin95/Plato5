# Volt Atelier

A boutique fitness studio site built with [Reflex](https://reflex.dev/) (pure Python). Volt Atelier is fictional: a small training floor in Port Meridian with a weekly class board, memberships, coaches, and a body lab.

The painting in `assets/background.jpg` is the background of every page. It is applied once on the page root with `background_size="cover"`, `background_position="center"`, and `background_attachment="fixed"`, so it stays locked while the page scrolls. Sections sit on semi-transparent dark panels so the text stays readable and the painting shows through.

## Python version

**Python 3.14.4.**

Current Reflex (`0.10.0`) supports Python 3.14. Support was added in Reflex 0.8.15 (October 2025). Reflex 0.10.0 requires Python `>=3.11,<4` and lists 3.11, 3.12, 3.13, 3.14, and 3.15 in its PyPI classifiers. This project targets **3.14.4** specifically and was run on that interpreter.

`.python-version` is set to `3.14.4`.

## Run on Ubuntu

### 1. Install Python 3.14.4

Ubuntu's default packages do not include this exact patch. Install it with [uv](https://docs.astral.sh/uv/), which downloads an official CPython build:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source "$HOME/.local/bin/env"
uv python install 3.14.4
python3.14 --version
```

You should see `Python 3.14.4`.

### 2. Clone, install, and run

```bash
git clone https://github.com/Gooberin95/Plato5.git
cd Plato5
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
reflex run
```

`reflex init` is not needed. This repo already has `rxconfig.py` and the `volt_atelier` package. Run it only if Reflex says the project is not initialized, and do not overwrite the existing files:

```bash
reflex init
```

### 3. Open the site

http://localhost:3000

The first `reflex run` downloads Reflex's frontend toolchain (Bun) and compiles the app. That can take a few minutes. The page to open is the frontend URL Reflex prints, which is http://localhost:3000 unless that port is already taken. The Python backend listens on http://localhost:8000.

Stop the app with Ctrl+C.

`reflex run` serves the app at `/` with the Python backend. The published site uses a different base path, described below.

## GitHub Pages

The live site is [https://gooberin95.github.io/Plato5/](https://gooberin95.github.io/Plato5/).

GitHub Pages only hosts static files, so it cannot run the Reflex backend or its websocket. A push to `main` runs `.github/workflows/pages.yml`, which installs Python 3.14.4, exports the frontend with `reflex export --frontend-only --no-zip`, and deploys that folder with GitHub's Pages actions. The export sets `REFLEX_FRONTEND_PATH=/Plato5` so scripts, styles, fonts, and `background.jpg` load under the project subpath. That variable also switches the pages to browser-side filters, toggles, and the body lab, and compiles the app with state disabled so the page does not open a backend socket. Local `reflex run` does not set the variable, so it stays at `/` and keeps Reflex state.

You can also start a deploy by hand from the Actions tab with "Deploy GitHub Pages".

The site source has to be GitHub Actions. While it stays on "Deploy from a branch", a push to `main` publishes the repository files and replaces this export. Under Settings, Pages, Build and deployment, choose Source: GitHub Actions.

## Azure App Service

`.github/workflows/deploy.yml` builds the same app for Azure App Service. That build does not set `REFLEX_FRONTEND_PATH`, so the site is served at `/` with the Reflex backend and its websocket. Staging and production deploys stay skipped until the repository variable `AZURE_DEPLOY_ENABLED` is `true`. The setup steps are in [DEPLOY.md](DEPLOY.md).

## What's in the site

- **Home** — hero, five training lanes, house rules, testimonials, and a plan preview.
- **Week** (`/schedule`) — a weekly class grid you can filter by lane. Open a session for the room, the cap, and the plan. Links like `/schedule?lane=Ride` preselect a lane.
- **Plans** (`/membership`) — Spark, Current, and Kiln, with a monthly/yearly toggle, an FAQ, and a trial request that stays in the browser session.
- **Coaches** (`/coaches`) — six profiles. Select one to read how they coach.
- **Lab** (`/lab`) — BMI scale and a calorie target (Mifflin–St Jeor) from the same inputs, in metric or imperial.

Navigation is a pill fixed to the bottom of the viewport. The wordmark stays in a translucent bar at the top.
